# Walidacja jednostek i serii

Kontrola ujawnia sprzeczności i zależności. Jej zakres, przeczytane źródła i niewykonane kroki są częścią wyniku; automat nie nadaje jakości literackiej.

## Identyfikatory i statusy

Powiąż tom, jednostkę, scenę, fakt i zasiew stabilnymi identyfikatorami, np. `T02-R07-S03`, `F-012`, `Z-008`. To przykłady, nie wymóg zmiany istniejącej numeracji. Krótki cytat i tytuł pomagają znaleźć miejsce po zmianie numerów linii.

Rozróżniaj: propozycja, plan przyjęty, napisane, sprawdzone w określonym zakresie, zmienione i porzucone. Przyjęty plan nie jest faktem napisanym. Puste pole może oznaczać brak kontroli, a nie brak problemu.

## Pięć poziomów

| Moment | Zakres |
|---|---|
| Przed pierwszym tomem | Architektura serii, warunki finału, chronologia, łuki i zależności ujawnień. |
| Przed jednostką | Stan wejścia, wiedza, motywacja, rekwizyty, wariant stylu i warunki przyszłych rozwiązań. |
| Po jednostce | Fakty, następstwa, styl, immersja, maniery, długość i zapis stanu. |
| Po module | Przejścia, przepływ informacji, tempo, powtarzane sytuacje i myśli, relacje i raporty. |
| Po tomie | Lokalna obietnica, długi wobec czytelnika, zasiewy przyszłości, stan kolejnego tomu i zgodność wstecz. |

Po finale sprawdź rozwiązania wstecz: czy przygotowano przesłanki, czy nie zmieniono znaczenia faktu bez podstawy i czy nie urwano wątku przypadkiem. Świadoma otwartość jest dopuszczalna, gdy odpowiada obietnicy książki.

## Wpływ zmiany

1. Wskaż starą i nową wersję oraz decyzję autora lub podstawę korekty.
2. Znajdź źródło faktu, użycia bezpośrednie i zależności pośrednie: wiedzę, motywację, alibi, chronologię i rozwiązania.
3. Oznacz status każdej zależności. Wyszukiwanie słów nie wykrywa wszystkich zależności znaczeniowych.
4. Popraw teksty i rejestry w autoryzowanym zakresie. Pozostałe skutki wskaż jawnie, nie oznaczaj ich jako wykonanych.
5. Przeczytaj zmienione sceny z wejściem i konsekwencją; uaktualnij stan, przyszły plan i eksporty.

## Waga ustaleń

- **Blokuje zależną scenę:** sprzeczna tożsamość, niemożliwa chronologia, brak źródła wiedzy lub przedmiotu.
- **Redakcja:** powtarzana motywacja, sztuczny dialog, utrata głosu, słabe przejście.
- **Decyzja autora:** wariant finału, zamierzona otwartość, zmiana konwencji.
- **Techniczne:** typografia, nagłówek, duplikat pliku, niespójny spis.

Zapis problemu: lokalizacja → obserwacja → źródło porównania → skutek → poprawka → wynik ponownej kontroli. Wpisanie błędu do raportu nie oznacza jego rozwiązania. Kosmetyczna usterka nie blokuje niezależnej pracy.
