# Eksporty

Tu zapisuj zamówione pliki wynikowe, np. połączony Markdown, DOCX, PDF lub EPUB. Ten szablon nie wykonuje konwersji. Czytelny README utrzymuje katalog w repozytorium bez potrzeby dodawania pustego `.gitkeep`.

| Plik wynikowy | Format | Źródła i spis kolejności | Wersja / commit źródeł | Data eksportu | Narzędzie i parametry | Kontrola treści | Kontrola wyglądu |
|---|---|---|---|---|---|---|---|

Zmiana źródła oznacza, że poprzedni eksport może być nieaktualny. Kontrola wyglądu obejmuje m.in. nagłówki, dialogi, polskie znaki i spis treści. Nie zaznaczaj jej jako wykonanej na podstawie samego poprawnego zakończenia konwersji.

Opcjonalne GitHub Actions można wdrożyć osobnym zadaniem po ustaleniu sposobu składania, narzędzi, fontów i formatów. Wygenerowanie pliku nie jest zgodą na jego publiczne udostępnienie.
